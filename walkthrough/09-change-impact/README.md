# Phase 09: Change impact ("a new rule landed: what must we change?")

This is the workflow compliance teams actually pay for. When a regulator issues or amends a
rule, someone has to work out what it obliges the firm to do, check each obligation against
the firm's own policies, and raise work for the gaps. RegLens drafts all of that and then
**stops for a human to review** before anything becomes a ticket.
